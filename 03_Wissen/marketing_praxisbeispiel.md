## Was aktuell (Stand Mai 2026) noch nicht gebraucht wird
| Tool/System | Warum noch nicht |
|---|---|
| Scompler | Für Teams mit 10+ Personen gebaut. Überdimensioniert. |
| GTM-OS (Raoul) | Für hohe Werbebudgets. Nicht die aktuelle Phase. |
| RevOps-Infrastruktur | Erst wenn organischer Traffic und Positionierung stehen |
| Komplexes Attribution-Tool (Hyros) | Kommt bei weiterer Skalierung |
| 5+ verschiedene Kampagnen | Erst eine perfektionieren |

**Goldene Regel:** Erst das Fundament – dann die Infrastruktur.

## Persönlicher Marketing-Stack (Anfangsphase)

| Tool | Aufgabe |
|------|---------|
| **Claude** | Strategie + Texte |
| **Canva** | Visuals & Bilder |
| **Buffer** | Posts planen & veröffentlichen |
| **Metricool** | Performance tracken |
| **GA4** | Attribution & Tracking |

### Workflow für einen Post (ca. 30 Min)
```
1. Claude (5 Min) → Phase + Zielgruppe + Framework wählen → Text
2. Canva (10 Min) → Foto auswählen, Text auf Bild (1080×1080px)
3. Buffer (5 Min) → Hochladen & planen (Empfehlung: Di–Do, 19–21 Uhr)
4. Automatische Veröffentlichung
5. Metricool nach 48h (5 Min) → Auswertung
6. Claude (5 Min) → Optimieren → nächster Zyklus
```

### Posting-Rhythmus
- 2× pro Woche organisch = ausreichend für Anfangsphase
- Inhalte aus KFC-System wiederverwenden – kein neuer Content nötig

## Persönlicher Aktionsplan (Stand Mai 2026)

```
Phase 1 (damals aktuell):
→ Funnel schließen (WhatsApp als einzigen CTA)
→ KFC-Kampagne live schalten
→ 2× pro Woche organisch posten

Phase 2 (Monat 2):
→ Kundenvokabular sammeln und einbauen
→ Identitäts-Content aufbauen
→ Erste Ergebnisse auswerten

Phase 3 (Monat 3+):
→ Was funktioniert skalieren
→ Budget schrittweise erhöhen
→ Zweite KFC-Anzeige hinzufügen
```
