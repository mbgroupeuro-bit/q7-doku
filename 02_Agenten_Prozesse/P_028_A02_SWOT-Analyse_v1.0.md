## SWOT-STRUKTUR

### INTERN

**Staerken (Strengths)**
```
Was macht der Kunde gut?
→ Physisch (aus Mystery Shopping)
→ Digital (aus Digital-Audit, P_024)
→ Produkt / Angebot
→ Service & Personal
→ Markenidentitaet (falls vorhanden)
```

**Schwaechen (Weaknesses)**
```
Wo hat der Kunde Defizite?
→ Physisch (aus Mystery Shopping)
→ Digital (aus Digital-Audit, P_024)
→ Produkt / Angebot
→ Prozesse & Strukturen
→ Markenidentitaet (falls fehlend oder inkonsistent)
```

### EXTERN

**Chancen (Opportunities)**
```
Was bietet der Markt?
→ Trends in der Branche
→ Unbesetzte Positionierungen
→ Wettbewerber-Schwaechen nutzbar?
→ Neue Zielgruppen erreichbar?
→ Digitale Wachstumschancen
```

**Risiken (Threats)**
```
Was bedroht den Kunden?
→ Starke Wettbewerber
→ Marktveraenderungen
→ Preisdruck
→ Fehlende Differenzierung
→ Digitale Sichtbarkeit verloren
```

## STRATEGIE-ABLEITUNGEN (Pflicht)

Aus der SWOT werden 4 Strategierichtungen abgeleitet:

```
SO-Strategie (Staerken + Chancen nutzen)
→ Wie nutzen wir Staerken um Chancen zu greifen?

ST-Strategie (Staerken + Risiken abwehren)
→ Wie nutzen wir Staerken um Risiken abzufedern?

WO-Strategie (Schwaechen + Chancen)
→ Wie ueberwinden wir Schwaechen um Chancen zu nutzen?

WT-Strategie (Schwaechen + Risiken minimieren)
→ Wie minimieren wir Schwaechen & Risiken gleichzeitig?
```
