## DIE 3 SCOPE-VARIANTEN

### VARIANTE A — VOLLSTÄNDIG

**Umfang:**
```
Alle Bereiche:
→ Markenidentität (Logo, CI, Tonalität, Guidelines)
→ Digital (Website, Social Media, Google Business, SEO, Bewertungen)
→ Produktion & Prozesse (interne Effizienz, Qualitätssicherung)
→ Finanzen (Kostenoptimierung, Margin-Analyse, Preismodell)
→ Personal (Organisationsstruktur, Team-Entwicklung)
→ Logistik (Lieferketten, Fuhrpark, Standort-Optimierung)
```

**Wann sinnvoll:**
```
Kunde ist etabliert + langfristige Partnerschaft angestrebt
Budget ist vorhanden (üblicherweise 6-stellig)
Inhaber ist aktiv bereit zu investieren
Strategischer Fokus auf tiefe Transformation
```

**Prozess-Vollablauf:**
```
P_019–P_023: Alle Schritte Standard
P_029 (Branchen-Benchmarks): VOLLSTÄNDIG (Finanz-KPIs, Betriebskennzahlen)
P_031 (Bedarfsanalyse): Alle 6 Bereiche analysiert
P_032 (Roadmap): 12-Monate Vollprogramm
```

**Deliverable P_033:**
```
Präsentation: 21 Folien Standard
PDF-Report: 12 Kapitel vollständig
```

---

### VARIANTE B — MARKENIDENTITÄT + DIGITAL *(häufigster Einstiegs-Scope)*

**Umfang:**
```
Fokus auf sichtbare Außenwirkung:
→ Markenidentität (Logo, CI, Tonalität, Guidelines) — PFLICHT
→ Digital (Website Redesign, Social Media Strategie, Google Business,
  Bewertungsmanagement, Sichtbarkeit)
→ Content & Positionierung

EXPLIZIT AUSGELASSEN:
❌ Produktion / interne Prozesse
❌ Finanzzahlen / Margin-Optimierung
❌ Personal / Organisationsstruktur
❌ Logistik / Lieferketten
```

**Wann sinnvoll:**
```
Kunde ist neu oder Vertrauensaufbau-Phase
Budget ist mittel (üblicherweise 4–5-stellig)
Schnelle Sichtbarkeits-Erfolge wichtig
Strategie: Erst Ergebnisse liefern, dann Scope erweitern
```

**Prozess-Anpassungen:**
```
P_019–P_023: Standard (Mystery Shopping, Digital Audit, SWOT)
P_029 (Branchen-Benchmarks): ENTFÄLLT KOMPLETT
P_030 (Gap-Analyse): nur physisch + digital, keine Finanzgaps
P_031 (Bedarfsanalyse): nur Marketing + Markenidentität
P_032 (Roadmap): nur Phase 1 (Fundament) + Phase 2 (Aufbau)
```

**Deliverable P_033:**
```
Präsentation: 18 Folien (Benchmarks-Kapitel entfällt)
PDF-Report: 10 Kapitel (kein Finanzkapitel)
```

**Offene Punkte-Logik (P_023):**
```
HINWEIS AN KUNDEN: Offene Punkte aus Kundengespräch zu Finanzen,
Personal oder Logistik werden NICHT aufgelöst in P_031 —
sie werden dokumentiert als "außerhalb aktueller Scope,
Potenzial für Phase 2".
```

---

### VARIANTE C — NUR DIGITAL

**Umfang:**
```
Nur externe Sichtbarkeit:
→ Website (falls keine vorhanden oder major Redesign)
→ Social Media Strategie & Setup
→ Google Business Optimierung
→ Bewertungsmanagement

KEINE Markenidentität neu erstellen (falls CI bereits gut ist)
KEINE physischen Analysen
KEINE Finanzen / Personal / Logistik
```

**Wann sinnvoll:**
```
Kunde hat bereits funktionierende Markenidentität
Budget sehr begrenzt (2–3-stellig)
Schnelle, fokussierte digitale Optimierung
Typisch: Lokale Geschäfte mit guter Offline-Präsenz, schwacher Online-Präsenz
```

**Prozess-Anpassungen:**
```
P_019: Mystery Shopping OPTIONAL (nur wenn vor Ort relevant)
P_024: Digital Audit Standard (Domain-Check ist Pflicht)
P_028–P_030: Reduziert auf Digital-fokussierte Gaps
P_031: Bedarfsanalyse nur digitale Bausteine
P_032: Roadmap 6 Monate statt 12 (schneller ROI)
```

**Deliverable P_033:**
```
Präsentation: 12 Folien (kompakt)
PDF-Report: 7 Kapitel (digital only)
```
