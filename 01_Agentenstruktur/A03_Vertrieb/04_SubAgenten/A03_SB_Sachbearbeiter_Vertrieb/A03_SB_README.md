## Ladereihenfolge beim Start eines Auftrags
1. `A03_SB_README.md` (Übersicht – zuerst lesen)
2. `A03_SB_agentenbeschreibung.md` (Identität)
3. `A03_SB_regeln.md` (Grundsätze)
4. `A03_SB_Skills.md` (Werkzeuge)
5. Briefing / konkreter Auftrag + zugehörige Prozessdatei (laut `loop.md`-Zuordnungstabelle)

## Prinzip
A03_SB bleibt bewusst schlank. Fachwissen zu einzelnen Auftragstypen (z. B. Angebotserstellung) liegt in externen Prozessdateien (`02_Prozesse`) und wird pro Auftrag zugewiesen – nicht dauerhaft im Agentenordner gespeichert.
