# A02_02 – Loop (Ablauflogik)

## Auswahllogik — wann welches Framework?

| Situation | Framework | Begründung |
|---|---|---|
| Neue Content-Strategie | Content Inc. Modell | Fundament zuerst |
| Redaktionsplan gefordert | Funnel-Content-Matrix | Nach Funnel strukturieren |
| Ein Artikel → viele Formate | Repurposing-Pyramide | Maximale Reichweite |
| B2B Fachpublikum | Schreibstil: Fachlich | Vertrauen aufbauen |
| Emotionale Bindung nötig | Schreibstil: Emotional | Community aufbauen |
| SEO-getriebener Content | Themencluster-Struktur | Mit A02_03 (SEO) abstimmen |

**Entscheidungsbaum:**
```
Neuer Auftrag?
    → Content-Strategie nötig: Content Inc. Modell
    → Nur Texte produzieren: Funnel-Stufe bestimmen → Schreibstil wählen
    → Ein Content → viele Kanäle: Repurposing-Pyramide
    → SEO-Content: Themencluster mit A02_03 abstimmen
```

## Ablauf pro Auftrag
1. Auftrag von A02 (Marketingleiter) entgegennehmen.
2. Abgleich mit Positioning-Grundlage von A02_01 — ohne diese kein Start.
3. Passendes Framework wählen (siehe Auswahllogik oben).
4. Content erstellen gemäß gewähltem Schreibstil und Funnel-Stufe.
5. Repurposing-Möglichkeiten mitdenken (Repurposing-Pyramide, siehe `A02_02_Skills.md`).
6. Qualitäts-Checkliste vor Auslieferung:
   - [ ] Funnel-Stufe klar definiert?
   - [ ] Zielgruppe direkt angesprochen?
   - [ ] Klarer Call-to-Action vorhanden?
   - [ ] Konsistent mit Positioning (A02_01)?
   - [ ] Repurposing-Möglichkeiten genannt?
   - [ ] KPIs definiert?
7. Mindest-Deliverables sicherstellen: Content-Strategie/Redaktionsplan, min. 1 fertiges Content-Piece, min. 3 Repurposing-Formate, KPIs.
8. Output zurück an A02 (Marketingleiter).
