# A02_12 – Loop (Ablauflogik)

## Auswahllogik — wann welches Framework?

| Situation | Framework | Begründung |
|---|---|---|
| Neue Marke aufbauen | Brand-Identitäts-Pyramide | Von innen nach außen |
| Marke differenzieren | ZAG Framework | Weißen Fleck finden |
| Strategie und Kreativität verbinden | The Brand Gap | Beide Seiten ausrichten |
| CI überarbeiten | Brand Audit + CI-Komponenten | Erst analysieren, dann ändern |
| Markenstimme definieren | Markenstimme-Framework | 3 Adjektive als Anker |

**Entscheidungsbaum:**
```
Neue Marke?
    → JA: Brand-Identitäts-Pyramide vollständig durchlaufen
    → NEIN: Bestehendes Branding-Problem?
        → Differenzierung schwach: ZAG Framework
        → CI inkonsistent: Brand Audit
        → Stimme unklar: Markenstimme-Framework
```

## Ablauf pro Auftrag
1. Auftrag von A02 (Marketingleiter) entgegennehmen.
2. Situation gegen Auswahllogik-Tabelle prüfen, Framework wählen.
3. **Bei neuer Marke:** Brand-Identitäts-Pyramide durchlaufen: Zweck → Vision → Mission → Werte → Persönlichkeit → Markenstimme → Visual Identity (siehe `A02_12_Skills.md`).
4. CI-Komponenten definieren (Logo, Farben max. 2 Primär, Typografie max. 2 Schriftfamilien, Bildsprache, Iconografie, Grid).
5. Markenstimme mit 3 Adjektiven + Beispielsätzen + Abgrenzung ("was es NICHT ist") festlegen.
6. Qualitäts-Checkliste vor Auslieferung:
   - [ ] Markenzweck in einem Satz formuliert?
   - [ ] Differenzierung klar vom Wettbewerb?
   - [ ] CI-Komponenten vollständig definiert?
   - [ ] Markenstimme mit 3 Adjektiven + Beispielen?
   - [ ] One-Page Brand Summary für andere Agenten erstellt?
   - [ ] Logo-Briefing umsetzbar für Designer?
7. Mindest-Deliverables sicherstellen: Brand Strategy, CI-Vorgaben, Markenstimme-Guide, One-Page Brand Summary (für alle anderen Agenten), Logo-Briefing (wenn nötig).
8. Output zurück an A02 (Marketingleiter) — dient als Grundlage für alle anderen Sub-Agenten (insbesondere A02_01 Strategie & Positioning).
