# A02_12 – Skills (Werkzeuge & Fähigkeiten)

## Kern-Definitionen (Neumeier)
- **Brand** ist nicht Logo oder CI — Brand ist das Bauchgefühl eines Menschen über ein Unternehmen
- **Branding** = systematischer Prozess, dieses Bauchgefühl zu formen
- **Brand Differentiation:** Nicht besser sein — anders sein

## The Brand Gap Framework
```
5 Disziplinen, die Strategie und Kreativität verbinden:

1. DIFFERENTIATE → Was macht uns einzigartig?
2. COLLABORATE → Interne Ausrichtung auf die Marke
3. INNOVATE → Kreative Lösungen für Markenprobleme
4. VALIDATE → Testen, ob Marke funktioniert
5. CULTIVATE → Marke kontinuierlich pflegen
```

## ZAG Framework (Neumeier)
```
Wenn alle ZIG → du ZAG
→ Finde den weißen Fleck im Markt
→ Sei das Gegenteil von dem, was alle anderen tun
→ Radikal differenzieren statt graduell verbessern
```

## Brand-Identitäts-Pyramide
```
ZWECK (Warum existieren wir?)
    ↓
VISION (Wo wollen wir hin?)
    ↓
MISSION (Was tun wir täglich?)
    ↓
WERTE (Woran glauben wir?)
    ↓
PERSÖNLICHKEIT (Wie treten wir auf?)
    ↓
MARKENSTIMME (Wie sprechen wir?)
    ↓
VISUAL IDENTITY (Wie sehen wir aus?)
```

## CI-Komponenten

| Komponente | Beschreibung | Beispiel |
|---|---|---|
| Logo | Primär + Varianten | Horizontal, Vertikal, Icon |
| Farben | Primär (1–2) + Sekundär (2–3) + Neutral | HEX, RGB, CMYK, Pantone |
| Typografie | Headline-Font + Body-Font | Max. 2 Schriftfamilien |
| Bildsprache | Stil, Motive, Verbotenes | Hell/Dunkel, Menschen/Produkt |
| Iconografie | Stil der Icons | Outline, Filled, Rounded |
| Abstände | Grid-System, Weißraum | 8px-Grid |

## Markenstimme-Framework
```
3 Adjektive, die die Marke beschreiben:
z.B. "direkt, mutig, menschlich"

Für jedes Adjektiv definieren:
- Was bedeutet es konkret?
- Wie klingt es in einem Satz?
- Was ist es NICHT?
```

## Brand-Audit-Checkliste
- Ist die Markenbotschaft klar in 1 Satz?
- Differenziert sich die Marke klar vom Wettbewerb?
- Ist CI konsistent über alle Kanäle?
- Stimmt Markenstimme mit Zielgruppe überein?
- Kennen alle Mitarbeiter die Markenwerte?
