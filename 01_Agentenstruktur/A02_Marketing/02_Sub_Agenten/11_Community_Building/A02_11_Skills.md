# A02_11 – Skills (Werkzeuge & Fähigkeiten)

## SPACES-Modell (David Spinks)
Community schafft Wert durch:
- **S = Support:** Mitglieder helfen sich gegenseitig
- **P = Product:** Feedback und Co-Creation
- **A = Acquisition:** Mitglieder werben neue Mitglieder
- **C = Contribution:** User-Generated Content
- **E = Engagement:** Bindung und Loyalität
- **S = Success:** Mitglieder erreichen ihre Ziele

## Community-Lebenszyklus
```
Phase 1: Gründung (0-50 Mitglieder)
    → Qualität vor Quantität
    → Founder persönlich präsent
    → Klare Regeln und Kultur setzen

Phase 2: Wachstum (50-500 Mitglieder)
    → Onboarding automatisieren
    → Super-User identifizieren
    → Rituale einführen

Phase 3: Reife (500+ Mitglieder)
    → Moderatoren aufbauen
    → Sub-Gruppen ermöglichen
    → Community-Events skalieren
```

## Onboarding-Sequenz
```
Tag 1: Willkommens-Nachricht (persönlich)
    → Vorstellungs-Frage stellen
    → Wichtigste Ressourcen teilen

Tag 3: Erste Interaktion fördern
    → Konkreten Diskussionsstarter senden
    → Auf Vorstellung reagieren

Tag 7: Check-in
    → Haben sie gefunden, was sie suchen?
    → Zu spezifischer Diskussion einladen

Tag 14: Aktivierungs-Challenge
    → Erste Community-Aktion zuweisen
```

## Engagement-Taktiken
- **Wöchentliche Frage:** Diskussion anstoßen
- **Mitglieder-Spotlight:** Mitglieder hervorheben
- **Challenges:** 30-Tage-Challenges mit Fortschritt
- **Live-Events:** AMA, Workshops, Roundtables
- **Anerkennungs-System:** Badges, Titel, Ranglisten

## Community-KPIs

| Metrik | Bedeutung | Ziel |
|---|---|---|
| DAU/MAU Ratio | Tägliche vs. monatliche Aktivität | >20% |
| Onboarding-Completion | % neue Mitglieder, die Onboarding abschließen | >60% |
| Post-Rate | % Mitglieder, die posten | >10% |
| Retention Rate | Mitglieder nach 90 Tagen noch aktiv | >50% |
| NPS | Würden sie Community empfehlen? | >40 |
