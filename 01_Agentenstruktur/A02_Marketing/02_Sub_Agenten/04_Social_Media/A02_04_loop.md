# A02_04 – Loop (Ablauflogik)

## Auswahllogik — wann welche Strategie?

| Situation | Strategie | Begründung |
|---|---|---|
| B2B Zielgruppe | LinkedIn-Fokus | Entscheider auf LinkedIn |
| Junge Zielgruppe unter 30 | TikTok + Instagram Reels | Native Plattformen der Zielgruppe |
| Brand Awareness aufbauen | Meinungs-Posts + Story-Posts | Reichweite und Vertrauen |
| Engagement steigern | Frage-Posts + Kommentar-Strategie | Algorithmus und Community |
| Produkt launchen | Jab-Jab-Jab-Right-Hook-Prinzip | Erst Mehrwert, dann Verkauf |
| Organische Reichweite | Nativ denken pro Plattform | Algorithmus bevorzugt natives Format |

## Ablauf pro Auftrag
1. Auftrag von A02 (Marketingleiter) entgegennehmen.
2. Zielgruppe/Ziel gegen Auswahllogik-Tabelle prüfen, Plattform(en) und Strategie festlegen.
3. Content nach Caption-Struktur erstellen (siehe `A02_04_Skills.md`): Hook → Problem/Situation → Lösung/Erkenntnis → CTA → Hashtags.
4. Jab-Jab-Jab-Right-Hook-Verhältnis einhalten (3:1, siehe `A02_04_regeln.md`).
5. Qualitäts-Checkliste vor Auslieferung:
   - [ ] Hook in erster Zeile stark genug?
   - [ ] Plattform-nativer Content?
   - [ ] Jab-Right-Hook-Verhältnis stimmt?
   - [ ] CTA klar und konkret?
   - [ ] Posting-Frequenz realistisch?
6. Mindest-Deliverables sicherstellen: Plattform-Strategie, 30-Tage-Posting-Kalender, 5 Caption-Vorlagen, Engagement-Playbook.
7. Engagement laufend: alle Kommentare innerhalb 1 Stunde beantworten (siehe Regeln).
8. Output zurück an A02 (Marketingleiter).
