# A02_07 – Skills (Werkzeuge & Fähigkeiten)

## CRO-Forschungs-Framework
```
1. Quantitative Analyse (Zahlen)
   → Google Analytics: Funnel-Abbrüche, Exit-Pages
   → Heatmaps: Klick-Verteilung, Scroll-Tiefe
   → A/B-Test-Ergebnisse

2. Qualitative Analyse (Gründe)
   → Session Recordings: Wie navigieren Nutzer?
   → User Surveys: Warum kaufen/kaufen sie nicht?
   → Customer Interviews

3. Hypothesen bilden
   → "Weil [Beobachtung], vermuten wir [Problem],
       daher testen wir [Änderung],
       um [Ziel] zu erreichen."
```

## Conversion-Barrieren (die 7 häufigsten)
1. Unklares Wertversprechen auf Seite
2. Zu viele Ablenkungen / Optionen
3. Mangelndes Vertrauen (kein Social Proof)
4. Schlechte mobile Darstellung
5. Zu langsame Ladezeit
6. Zu langer / komplizierter Checkout
7. Falsche Zielgruppe angesprochen

## Hypothesen-Priorisierung (PIE-Modell)
- **P = Potential:** Wie groß ist der Einfluss?
- **I = Importance:** Wie wichtig ist diese Seite?
- **E = Ease:** Wie einfach umzusetzen?
- Score 1–10 pro Kategorie → Durchschnitt = Priorität

## Landing Page Struktur (High-Converting)
```
1. Hero: Headline + Subheadline + CTA
2. Problem: Schmerz benennen
3. Lösung: Produkt/Angebot vorstellen
4. Features → Benefits
5. Social Proof (Reviews, Zahlen, Logos)
6. FAQ (häufigste Einwände entkräften)
7. Final CTA mit Dringlichkeit/Garantie
```

## A/B-Test-Regeln
- Nur eine Variable gleichzeitig testen
- Min. 95 % statistische Signifikanz abwarten
- Min. 100 Conversions pro Variante vor Entscheidung
- Testdauer: min. 2 Wochen (Wochentag-Effekte)
