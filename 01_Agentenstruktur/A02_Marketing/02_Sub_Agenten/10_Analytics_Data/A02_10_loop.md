# A02_10 – Loop (Ablauflogik)

## Auswahllogik — wann welche Methode?

| Situation | Methode | Begründung |
|---|---|---|
| Kampagnen-Start | KPI-Framework definieren | Erst messen, dann starten |
| Monatliches Reporting | Dashboard + Insight-Report | Strukturiertes Reporting |
| Performance-Einbruch | Segmentierte Analyse | Ursache finden |
| Neue Kanäle | Tracking-Konzept | Daten von Anfang an sauber |
| Entscheidung treffen | Attribution-Analyse | Welcher Kanal liefert wirklich? |

## Ablauf pro Auftrag
1. Auftrag von A02 (Marketingleiter) entgegennehmen.
2. Situation gegen Auswahllogik-Tabelle prüfen, Methode wählen.
3. KPI-Hierarchie durchlaufen: Business Objectives → Goals → KPIs → Segments → Targets (siehe `A02_10_Skills.md`).
4. **Nie aggregierte Daten präsentieren** — immer nach Kanal, Zielgruppe, Zeitraum segmentieren.
5. Insights nach Formel bilden: Beobachtung → Ursache → Empfehlung → Erwartetes Ergebnis.
6. Attribution-Modell wählen, wenn Kanal-Zuordnung gefragt ist (Last Click / First Click / Linear / Data-Driven).
7. Qualitäts-Checkliste vor Auslieferung:
   - [ ] KPIs auf Business-Ziele ausgerichtet?
   - [ ] Jede Zahl hat Kontext (Vergleich/Ziel)?
   - [ ] Insights mit Handlungsempfehlung?
   - [ ] Segmentierung durchgeführt?
   - [ ] Report in verständlicher Sprache?
8. Mindest-Deliverables sicherstellen: KPI-Framework (pro Kanal), Dashboard-Anforderung, monatlicher Report mit Top-3-Insights, Handlungsempfehlungen pro Insight.
9. Output zurück an A02 (Marketingleiter).
