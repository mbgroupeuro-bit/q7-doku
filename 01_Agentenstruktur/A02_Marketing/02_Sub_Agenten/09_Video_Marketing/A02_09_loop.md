# A02_09 – Loop (Ablauflogik)

## Auswahllogik — wann welche Methode?

| Situation | Methode | Begründung |
|---|---|---|
| Neuer YouTube-Kanal | Kanal-Strategie + Content-Plan | Fundament legen |
| Niedriger CTR | Thumbnail + Titel optimieren | Direkteste Wirkung |
| Niedrige Watch Time | Script-Struktur überarbeiten | Retention-Zonen fehlen |
| Video-Ideen gesucht | Keyword-Recherche + Trendanalyse | Was sucht die Zielgruppe? |
| Video-Script gefordert | Retention-Script-Struktur | Maximale Zuschauerbindung |

## Ablauf pro Auftrag
1. Auftrag von A02 (Marketingleiter) entgegennehmen.
2. Situation gegen Auswahllogik-Tabelle prüfen, Methode wählen.
3. Bei Script: Retention-optimierte Struktur nutzen (Hook 0:00–0:30 → Intro → Main Content mit Retention-Zonen alle 2–3 Min. → CTA-Ende, siehe `A02_09_Skills.md`).
4. Thumbnail-Briefing nach Thumbnail-Formel erstellen (Emotion, Text max. 4 Wörter, Kontrastfarben, ein Fokuspunkt).
5. Titel nach Framework erstellen (Neugier-Lücke/Nutzen/Listicle/Kontrovers, Keyword vorne, max. 60 Zeichen), min. 3 Varianten.
6. Video-SEO: Beschreibung (erste 150 Zeichen entscheidend), Keyword in ersten 25 Wörtern, 5–10 Tags, Kapitel-Timestamps bei längeren Videos.
7. Qualitäts-Checkliste vor Auslieferung:
   - [ ] Hook in ersten 30 Sekunden stark?
   - [ ] Script mit Retention-Zonen?
   - [ ] Thumbnail-Briefing vollständig?
   - [ ] Titel mit Keyword und Neugier-Element?
   - [ ] CTA konkret und platziert?
   - [ ] Video-SEO (Beschreibung, Tags) optimiert?
8. Mindest-Deliverables sicherstellen: vollständiges Video-Script, Thumbnail-Briefing, Titel (3 Varianten), Beschreibung + Tags.
9. Output zurück an A02 (Marketingleiter).
