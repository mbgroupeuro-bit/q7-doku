# A02_09 – Skills (Werkzeuge & Fähigkeiten)

## YouTube-Algorithmus Kern-Faktoren
- **CTR (Click-Through-Rate):** Thumbnail + Titel entscheidend (Ziel: >5%)
- **Watch Time:** Wie lange schauen Zuschauer? (Ziel: >50%)
- **Engagement:** Likes, Kommentare, Shares
- **Subscriber-Wachstum:** Nach Video geklickt?

## Thumbnail-Formel
```
Element 1: Gesicht mit starker Emotion (Überraschung/Freude)
Element 2: Klarer Text (max. 4 Wörter, groß)
Element 3: Kontrastreiche Farben (zum Kanal passend)
Element 4: Ein visueller Fokuspunkt (kein Chaos)
Vermeide: Zu viel Text, unklare Bildaussage, schlechte Lesbarkeit
```

## Titel-Framework
- **Neugier-Lücke:** "Das weiß kaum jemand über X"
- **Nutzen-Versprechen:** "Wie du X in Y Tagen erreichst"
- **Listicle:** "7 Fehler, die jeden X kosten"
- **Kontroverses Statement:** "Warum X falsch liegt"
- Keyword vorne im Titel (SEO)
- Max. 60 Zeichen

## Script-Struktur (Retention-optimiert)
```
0:00-0:30 HOOK
    → Was gibt es zu sehen? (Tease das Ende)
    → Warum sollte man weiterschauen?
    → Pattern Interrupt (Überraschung)

0:30-1:30 INTRO
    → Kurze Vorstellung des Themas
    → Subscribe-Hinweis (mit Begründung)

1:30-X MAIN CONTENT
    → Retention-Zonen alle 2-3 Minuten
    → Zwischenfragen / Interaktion einbauen
    → B-Roll und Schnitte für Abwechslung

Ende CTA
    → Konkrete Handlungsaufforderung
    → Verweis auf nächstes Video (Endscreen)
```

## Video-SEO
- Beschreibung: erste 150 Zeichen entscheidend (Vorschau)
- Keywords: Haupt-Keyword in ersten 25 Wörtern
- Tags: 5–10 relevante Tags (nicht spammen)
- Kapitel: Timestamps für längere Videos
- Endscreen: 2 Video-Empfehlungen + Subscribe
- Cards: Links und Hinweise im Video

## KPIs YouTube
