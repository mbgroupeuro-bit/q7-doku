# A02_01 – Loop (Ablauflogik)

## Zweck
Beschreibt, wann welches Framework eingesetzt wird und wie ein Strategie-Auftrag Schritt für Schritt bearbeitet wird.

## Auswahllogik — wann welches Framework?

| Situation | Framework | Begründung |
|---|---|---|
| Neues Produkt / neue Marke | Obviously Awesome (vollständig) | Grundlage für alles |
| Repositionierung nötig | Obviously Awesome + Wettbewerbs-Matrix | Erst verstehen, wo man steht |
| Zielgruppe unklar | Persona Framework | Ohne Zielgruppe keine Strategie |
| Wettbewerber analysieren | Wettbewerbs-Matrix + Gap-Analyse | Chancen sichtbar machen |
| UVP unklar | Positioning Statement Template | Klarheit in einem Satz |
| Neue Marktkategorie | Kategorie-Strategie | Eigene Regeln setzen |

**Entscheidungsbaum:**
```
Ist das Produkt/die Marke neu?
    → JA: Obviously Awesome vollständig durchlaufen
    → NEIN: Ist die Positionierung unklar?
        → JA: Wettbewerbs-Matrix + Gap-Analyse
        → NEIN: Ist nur die Zielgruppe unklar?
            → JA: Persona Framework
            → NEIN: Positioning Statement schärfen
```

## Positioning-Prozess (Obviously Awesome, 7 Schritte)
1. Beste Kunden identifizieren
2. Competitive Alternatives ermitteln
3. Unique Attributes herausarbeiten
4. Wert dieser Attribute definieren
5. Zielgruppe schärfen
6. Marktkategorie wählen
7. Positioning Statement formulieren

## Qualitäts-Checkliste vor Auslieferung
- [ ] Zielgruppe klar und spezifisch definiert?
- [ ] UVP in einem Satz formulierbar?
- [ ] Wettbewerber konkret benannt?
- [ ] Positioning Statement vollständig?
- [ ] Nächste Schritte genannt?
- [ ] Keine unbegründeten Annahmen?

## Mindest-Deliverables
1. Positioning Statement (1 Satz)
2. Zielgruppen-Persona (mind. 1)
3. Top-3-Wettbewerber mit Unterschied
4. Empfohlene Marktkategorie
5. Strategische Empfehlungen für andere Agenten

Output geht immer zurück an A02 (Marketingleiter) als Briefing-Grundlage für die weiteren Sub-Agenten.
