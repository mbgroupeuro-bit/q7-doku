# A02_05 – Skills (Werkzeuge & Fähigkeiten)

## Customer Value Journey (CVJ)
```
1. Aware → 2. Engage → 3. Subscribe → 4. Convert → 5. Excite → 6. Ascend → 7. Advocate → 8. Promote
```
Paid Ads aktivieren je nach Funnel-Stufe unterschiedliche Kampagnentypen.

## Kampagnenstruktur (Testing → Scaling)

**Test-Phase:**
- 5–10 verschiedene Creatives
- 3–5 Zielgruppen parallel
- Kleines Budget (10–20 % des Gesamtbudgets)
- Ziel: Gewinner identifizieren

**Scaling-Phase:**
- Gewinner-Creatives skalieren
- Lookalike Audiences aufbauen
- Budget schrittweise erhöhen (+20 % alle 3 Tage)
- Retargeting-Layer hinzufügen

## Ad-Copy Framework (Hook-Body-CTA)
```
HOOK (erste 3 Sekunden / erste Zeile)
    → Problem benennen ODER
    → Überraschende Aussage ODER
    → Direkte Ansprache der Zielgruppe

BODY
    → Problem vertiefen
    → Lösung präsentieren
    → Beweise/Social Proof

CTA
    → Eine klare Handlung
    → Dringlichkeit oder Anreiz
    → Konkret ("Jetzt kostenlos testen")
```

## KPI-Framework

| Metrik | Benchmark | Bedeutung |
|---|---|---|
| CTR (Click-Through-Rate) | >2% | Creative-Qualität |
| CPC (Cost per Click) | Branchenabhängig | Effizienz |
| CPL (Cost per Lead) | <Kundenlebenswert/10 | Lead-Qualität |
| ROAS (Return on Ad Spend) | >3x | Profitabilität |
| CPA (Cost per Acquisition) | <Produktmarge | Wirtschaftlichkeit |

## Plattform-Spezifika
- **Meta (FB/IG):** Breite Zielgruppen, visuell, Retargeting stark
- **Google Search:** Hohe Kaufabsicht, keyword-basiert
- **Google Display:** Brand Awareness, günstiger CPM
- **TikTok:** Junge Zielgruppe, native Video-Content, Hook entscheidend
