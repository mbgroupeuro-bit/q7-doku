# A02_05 – Loop (Ablauflogik)

## Auswahllogik — wann welche Plattform/Methode?

| Situation | Plattform/Methode | Begründung |
|---|---|---|
| Hohe Kaufabsicht | Google Search | Nutzer suchen aktiv |
| Brand Awareness | Meta oder TikTok | Breite Reichweite |
| Junge Zielgruppe | TikTok | Native Plattform |
| B2B Lead-Gen | LinkedIn Ads | Entscheider erreichbar |
| Retargeting | Meta | Stärkste Retargeting-Möglichkeiten |
| Neues Produkt testen | Test-Phase-Struktur | Erst Gewinner finden |
| Bewährtes Produkt skalieren | Scaling-Phase | Budget erhöhen auf Gewinnern |

## Ablauf pro Kampagne
1. Auftrag von A02 (Marketingleiter) entgegennehmen.
2. Situation gegen Auswahllogik-Tabelle prüfen, Plattform + Phase (Test/Scaling) festlegen.
3. **Test-Phase:** 5–10 Creatives, 3–5 Zielgruppen parallel, 10–20 % des Gesamtbudgets, Ziel: Gewinner identifizieren.
4. Ad-Copy nach Hook-Body-CTA-Framework erstellen (siehe `A02_05_Skills.md`), min. 3 Varianten.
5. Creatives-Briefing für Designer erstellen.
6. **Scaling-Phase** (nach positiver ROAS): Gewinner-Creatives skalieren, Lookalike Audiences aufbauen, Budget schrittweise erhöhen (+20 % alle 3 Tage), Retargeting-Layer ergänzen.
7. Qualitäts-Checkliste vor Auslieferung:
   - [ ] Kampagnenstruktur Test vs. Scale definiert?
   - [ ] Min. 3 Ad-Copy-Varianten vorhanden?
   - [ ] KPIs mit Benchmarks definiert?
   - [ ] Zielgruppen-Segmente klar?
   - [ ] Budget-Aufteilung begründet?
   - [ ] Creatives-Briefing vollständig?
8. Wöchentliche Performance-Reports gegen KPI-Benchmarks (siehe `A02_05_Skills.md`).
9. Output zurück an A02 (Marketingleiter).
