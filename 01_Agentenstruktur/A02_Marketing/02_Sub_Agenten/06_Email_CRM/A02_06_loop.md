# A02_06 – Loop (Ablauflogik)

## Auswahllogik — wann welche Sequenz?

| Situation | Sequenz/Methode | Begründung |
|---|---|---|
| Neuer Subscriber | Willkommens-Sequenz | Erste Beziehung aufbauen |
| Inaktive Subscriber | Reaktivierungs-Sequenz | Verluste minimieren |
| Laufende Kundenpflege | Pflege-Sequenz | Retention maximieren |
| Niedrige Öffnungsrate | Betreffzeilen-A/B-Test | Direkte Wirkung |
| Zu breiter Verteiler | Segmentierungslogik | Relevanz erhöhen |
| Produkt-Launch | Launch-Sequenz (5–7 E-Mails) | Dringlichkeit aufbauen |

## Ablauf pro Auftrag
1. Auftrag von A02 (Marketingleiter) entgegennehmen.
2. Situation gegen Auswahllogik-Tabelle prüfen, passende Sequenz wählen (siehe `A02_06_Skills.md` für Sequenz-Vorlagen).
3. Sequenz vollständig ausschreiben, Betreffzeilen nach Framework erstellen (min. 5 Varianten).
4. Segmentierung festlegen (Verhalten, Kaufhistorie, Interessen, Funnel-Stufe).
5. Qualitäts-Checkliste vor Auslieferung:
   - [ ] Sequenz vollständig ausgeschrieben?
   - [ ] Betreffzeilen: min. 3 Varianten?
   - [ ] Segmentierung definiert?
   - [ ] CTA in jeder E-Mail vorhanden?
   - [ ] DSGVO-konform?
   - [ ] KPIs definiert?
6. Mindest-Deliverables sicherstellen: vollständige Sequenz (min. 3 E-Mails), 5 Betreffzeilen-Varianten, Segmentierungs-Empfehlung, KPI-Benchmarks.
7. Output zurück an A02 (Marketingleiter).
