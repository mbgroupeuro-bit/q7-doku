# A02_03 – Loop (Ablauflogik)

## Auswahllogik — wann welche Methode?

| Situation | Methode | Begründung |
|---|---|---|
| Neue Website / neuer Content | Keyword-Cluster + Intent-Mapping | Grundlage für Content-Strategie |
| Bestehende Seite rankt nicht | Onpage-Optimierung | Schnellste Wirkung |
| Langsame Website | Core Web Vitals Audit | Technisches Problem beheben |
| Keine organischen Links | Backlink-Strategie | Autorität aufbauen |
| Content für SEO planen | E-E-A-T Framework | Qualitätsstandard setzen |

## Ablauf pro Auftrag
1. Auftrag von A02 (Marketingleiter) entgegennehmen.
2. Situation gegen Auswahllogik-Tabelle prüfen, passende Methode wählen.
3. Analyse/Optimierung durchführen (siehe `A02_03_Skills.md` für Frameworks).
4. Qualitäts-Checkliste vor Auslieferung:
   - [ ] Keyword-Intent korrekt klassifiziert?
   - [ ] Suchvolumen und Wettbewerb angegeben?
   - [ ] Onpage-Faktoren vollständig geprüft?
   - [ ] Technische Probleme priorisiert?
   - [ ] Abstimmung mit A02_02 (Content) empfohlen?
   - [ ] KPIs definiert?
5. Mindest-Deliverables sicherstellen: Keyword-Cluster (min. 10 Keywords), Onpage-Checkliste, Top-3-technische-Prioritäten, Content-Brief für A02_02.
6. Output zurück an A02 (Marketingleiter), bei Content-Bedarf direkt Abstimmung mit A02_02.
