# A02_03 – Skills (Werkzeuge & Fähigkeiten)

## Keyword-Framework

**Intent-Typen:**
- **Informational:** "Was ist X" → Blogpost, Guide
- **Navigational:** "X Website" → Brand-Seite
- **Commercial:** "Bestes X" → Vergleich, Review
- **Transactional:** "X kaufen" → Produktseite, Landing Page

**Keyword-Cluster-Struktur:**
```
Haupt-Keyword (Pillar)
    → Long-Tail Variante 1
    → Long-Tail Variante 2
    → Frage-Keywords (W-Fragen)
    → Semantisch verwandte Keywords
```

## Onpage-Optimierung Checkliste
- Title Tag: Haupt-Keyword vorne, max. 60 Zeichen
- Meta Description: Keyword + CTA, max. 160 Zeichen
- H1: Genau einmal, enthält Haupt-Keyword
- H2–H6: Strukturiert, LSI-Keywords einbauen
- Interne Links: min. 3 pro Artikel
- Bilder: Alt-Tags mit Keywords
- URL: Kurz, sprechend, mit Keyword
- Ladezeit: unter 3 Sekunden

## E-E-A-T Framework (Google)
- **Experience:** Eigene Erfahrungen zeigen
- **Expertise:** Fachkompetenz belegen
- **Authoritativeness:** Referenzen und Backlinks
- **Trustworthiness:** Transparenz und Genauigkeit

## Technisches SEO
- Core Web Vitals (LCP, FID, CLS)
- Mobile-First-Indexierung
- Crawlbarkeit und Indexierung
- Schema Markup / Strukturierte Daten
- HTTPS und Sicherheit
- Duplicate Content vermeiden

## Backlink-Strategie
- Guest Posting auf relevanten Seiten
- HARO (Help a Reporter Out)
- Broken Link Building
- Skyscraper Technique
- Digital PR (mit A02_08 PR/Outreach abstimmen)
