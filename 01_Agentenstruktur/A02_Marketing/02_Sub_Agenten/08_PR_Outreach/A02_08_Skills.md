# A02_08 – Skills (Werkzeuge & Fähigkeiten)

## Ryan Holiday Kern-Prinzipien
- **Earned Media > Paid Media:** Glaubwürdigkeit durch redaktionelle Erwähnung
- **Story first:** Journalisten brauchen eine Geschichte, kein Produkt
- **Newsjacking:** Aktuelle Themen für eigene Botschaft nutzen
- **Long game:** Beziehungen aufbauen, nicht nur Pitches senden

## Pitch-Framework (RARE)
- **R = Relevant:** Passt die Story zum Medium und Publikum?
- **A = Actionable:** Gibt es einen konkreten Aufhänger/News-Wert?
- **R = Research:** Zeige, dass du den Journalisten kennst
- **E = Exclusive:** Biete wenn möglich Exklusivität an

## Pitch-E-Mail Struktur
```
Betreffzeile: [Konkretes Thema] — kurz und spezifisch

Absatz 1: Direkter Einstieg (keine Floskeln)
    → Was ist die Geschichte in einem Satz?

Absatz 2: Warum relevant für deren Leser?
    → Daten, Trend, Timing

Absatz 3: Dein Unternehmen/Experte
    → Warum qualifiziert?

Absatz 4: CTA
    → Konkrete Anfrage (Interview, Gastbeitrag, Zitat)

Signatur + Social Proof (Erwähnungen, Follower, Buch)
```

## Themen-Hijacking (Newsjacking)
```
1. Trending Thema identifizieren (Google Trends, Twitter)
2. Verbindung zur eigenen Expertise herstellen
3. Einzigartigen Winkel / Kommentar entwickeln
4. Innerhalb 2-4 Stunden pitchen (Zeitfenster klein!)
5. Eigene Daten oder Studien einbauen
```

## Backlink-Outreach
- Skyscraper Technique: Besseren Content als Verlinkter erstellen
- Broken Link Building: Defekte Links durch eigene ersetzen
- HARO: Expert-Zitate für Journalisten liefern
- Guest Posting: Gastbeiträge auf relevanten Seiten

## Follow-up-Regel
- Follow-up 1: nach 3 Tagen (freundliche Erinnerung)
- Follow-up 2: nach 7 Tagen (neuer Aufhänger)
- Follow-up 3: nach 14 Tagen (letzter Versuch)
- Danach: kein weiterer Kontakt (Reputation schützen)
