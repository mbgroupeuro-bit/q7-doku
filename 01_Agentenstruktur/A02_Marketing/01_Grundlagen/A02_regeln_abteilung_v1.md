## 1. GRUNDREGELN


## 2. ZUSTÄNDIGKEITEN

```
✅ DARF:

→ Markenidentität analysieren & entwickeln
→ Content erstellen (Social Media, Website, Werbemittel)
→ Präsentationen erstellen (P_016.10)

❌ DARF NICHT:

→ Strategische Entscheidungen ohne GF treffen
→ Budget-Entscheidungen treffen

```
